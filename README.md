# 위로드 (WeRoad)

위펀오피스(office.wefun.kr) 위에서 열리는 운송 현황 패널입니다. 기사별·일별 방문 거래처와 매출, 기사 업무현황, 기사마스터(소속)를 보여줍니다. 데이터는 사용자가 로그인한 위펀오피스 세션으로 직접 읽고, 별도 서버는 없습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/weroad.js` | 패널 코드. **main 브랜치 = 개발 버전** |
| `release.json` | `stable`에 적힌 태그가 **일반 사용자 버전** |
| `install.html` | 북마크 설치 페이지 (일반용 / 개발자용) |

## 채널

| 채널 | 북마크 | 불러오는 코드 |
| --- | --- | --- |
| 정식 (stable) | `위로드` | `release.json`의 `stable` 태그 → jsDelivr `@태그/src/weroad.js` |
| 개발 (dev) | `위로드 DEV` | GitHub main 브랜치의 `src/weroad.js` (패널에 DEV 표시) |

## 개발 → 배포 절차

1. **개발**: `src/weroad.js`를 수정해 main에 커밋합니다. 개발자용 북마크로 확인합니다. GitHub 캐시 때문에 반영까지 최대 5분 정도 걸릴 수 있습니다.
2. **배포**: GitHub → Releases → *Draft a new release* → 태그 `v1.3.0`처럼 새 버전으로 발행합니다.
3. **공개**: `release.json`의 `stable`을 그 태그로 바꾸고 `history` 맨 위에 한 줄을 추가해 커밋합니다. 이때부터 일반 사용자가 새 버전을 봅니다.
4. **되돌리기**: `release.json`의 `stable`을 이전 태그로 바꾸면 바로 이전 버전으로 돌아갑니다.

버전 번호는 코드 안 `VERSION`과 태그를 같게 맞춥니다.

## 주의

- 공개 저장소입니다. 코드에 비밀번호, 토큰, 기사·거래처 등 실제 데이터를 넣지 않습니다.
- 개발/정식 구분은 "어떤 버전을 보느냐"의 구분이지 보안 권한이 아닙니다. 데이터 접근 권한은 위펀오피스 로그인 권한을 그대로 따릅니다.
- 소속 설정과 수집 데이터는 각 사용자 브라우저에 저장됩니다.
