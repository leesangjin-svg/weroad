위로드 (WeRoad) · 북마크 설치

북마크는 한 번만 설치하면 됩니다. 누를 때마다 GitHub에 올라간 코드를 불러오므로, 새 버전이 나와도 다시 설치할 필요가 없습니다.

1. 저장소 확인

2. 북마크바로 끌어다 놓기

일반 사용자용 — 정식 배포(stable) 버전만 열립니다.
위로드
개발자용 — 아직 배포 전인 최신 개발(main) 버전이 열립니다. 패널에 DEV 표시가 붙습니다. 개발자 본인만 설치하세요.
위로드 DEV

끌어다 놓기가 안 되면: 코드 복사 → 북마크바 우클릭 → 페이지 추가 → URL에 붙여넣기.

사용법

  1. 위펀오피스(office.wefun.kr)에 로그인된 화면에서 북마크를 누르면 패널이 열립니다.
  2. 화면을 이동하거나 새로고침하면 닫히므로 다시 누르세요.
  3. 소속 설정과 수집 데이터는 각자의 브라우저에 저장됩니다. 소속은 기사마스터 탭의 내보내기·붙여넣기로 공유하세요.
